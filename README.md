# De werkbonusval

Interactieve grafiek die toont welk deel van een bruto loonsverhoging een Belgische bediende (voltijds, alleenstaand) netto overhoudt, met tarieven 2026. Door de afbouw van de sociale en fiscale werkbonus houd je bij een brutoloon tussen €2.300,62 en €2.937,93 maar ongeveer 16% van een opslag over.

Live: https://xinirnix.github.io/werkbonusval/

Bronnen en aannames staan onderaan de pagina. De bedrijfsvoorheffing is een benadering van de sleutelformule (Bijlage III KB/WIB 92).
